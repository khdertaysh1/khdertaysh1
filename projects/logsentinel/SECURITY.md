# Security policy

This experimental local analysis tool has no telemetry and sends no network requests. Input files may be sensitive or untrusted. Use synthetic fixtures for public reports.

To report an implementation vulnerability privately, use this repository's GitHub **Security → Report a vulnerability** when enabled. Otherwise contact the maintainer through their GitHub profile without posting exploit details or secrets in a public issue.

Version 0.1.x receives fixes on the main branch. Reports are observations, not proof of exploitation or severity. Review generated output before sharing: route paths, field names and log IP addresses can identify people or systems. Never publish raw captures.
